# LEAF Presentations για Windows

## Δημιουργία installer στο δικό σου PC

1. Εγκατάστησε Node.js 22.12+ ή 24 και αποσυμπίεσε το ZIP.
2. Τρέξε `BUILD-WINDOWS.cmd` από τον κύριο φάκελο. Απαιτείται internet για τις εξαρτήσεις και τα εργαλεία πακεταρίσματος.
3. Αν ολοκληρωθεί επιτυχώς, θα ανοίξει ο φάκελος `desktop/out/make/squirrel.windows/x64`.
4. Δώσε στους συνεργάτες το `LEAF-Presentations-Setup.exe`. Δεν χρειάζονται Node.js ή Git. Πρόκειται για Windows x64 installer.

Εναλλακτικά από terminal:

```bash
npm ci
npm run desktop:setup
npm run desktop:make
```

Για δοκιμή της desktop εφαρμογής πριν το πακετάρισμα:

```bash
npm run desktop:start
```

Το `desktop:setup` εγκαθιστά τις εξαρτήσεις Electron χωριστά από το React project. Επειδή το περιβάλλον παράδοσης μπλόκαρε τη λήψη τους, δεν περιλαμβάνεται desktop lockfile. Μετά την πρώτη επιτυχή εγκατάσταση, κάνε commit το `desktop/package-lock.json` και χρησιμοποίησε `npm --prefix desktop ci` αντί για `desktop:setup` στο CI, ώστε να κλειδώσεις ακριβώς τις εκδόσεις.

## Μέσω GitHub

Αν ανεβάσεις το περιεχόμενο του κύριου φακέλου στη ρίζα του repository, περιλαμβάνεται workflow `.github/workflows/windows-installer.yml`.
Άνοιξε Actions → Build Windows installer → Run workflow. Μετά από επιτυχή εκτέλεση κατέβασε το artifact LEAF-Windows-Installer και αποσυμπίεσέ το. Το workflow δεν δημοσιεύει release και δεν ενεργοποιείται αυτόματα σε κάθε push.

Κάνε commit κώδικα, assets και lockfiles. Όχι `node_modules`, `dist`, `desktop/out` ή προσωπικά αρχεία έργων. Το `.gitignore` έχει ενημερωθεί.

## Χρήση από συνεργάτες

- Άνοιγμα από το εικονίδιο LEAF Presentations μετά την εγκατάσταση.
- Αποθήκευση/άνοιγμα έργου με κανονικό παράθυρο επιλογής αρχείου Windows.
- Εξαγωγή PDF → Αποθήκευση PDF: σταθερό μέγεθος 16:9 και φόντα, χωρίς ρυθμίσεις browser.
- Τα `.leaf.json` παραμένουν συμβατά με την έκδοση web. Μετέφερε πρώτα τα υπάρχοντα έργα με εξαγωγή από τον browser και εισαγωγή στην desktop εφαρμογή.
- Το αυτόματο πρόχειρο είναι ξεχωριστό για κάθε εγκατάσταση/χρήστη και δεν συγχρονίζεται. Αποθήκευε τα έργα ως αρχεία για backup.
- Νέα έκδοση: αύξησε το version στο `desktop/package.json`, δημιούργησε νέο installer και διένειμέ τον. Αυτόματες ενημερώσεις δεν έχουν υλοποιηθεί.

## Έλεγχος πριν τη διανομή

Στο περιβάλλον παράδοσης πέρασαν το React build και τα Node tests, αλλά η εγκατάσταση Electron αποκλείστηκε από τον δικτυακό περιορισμό. Δεν δημιουργήθηκε ούτε δοκιμάστηκε εκτελέσιμο Windows.

Στο Windows PC έλεγξε: εγκατάσταση → άνοιγμα παραδείγματος → αλλαγή τιμής και φωτογραφίας → αποθήκευση → ακύρωση διαλόγου χωρίς απώλεια αλλαγών → επανεισαγωγή → κλείσιμο/επαναφορά → PDF 18 σελίδων με φωτογραφίες και σωστά περιθώρια. Δοκίμασε τον installer και σε δεύτερο PC χωρίς Node.js.

Ο installer δεν είναι ψηφιακά υπογεγραμμένος. Τα Windows μπορεί να εμφανίσουν προειδοποίηση εκδότη/SmartScreen. Για υπογεγραμμένη διανομή απαιτείται ξεχωριστή ρύθμιση code signing· μην το αντιμετωπίζεις απενεργοποιώντας την προστασία των Windows.

## Όρια και CRM

Δεν υπάρχει backend, login, κοινή βάση, αποστολή email ή αυτόματη αφαίρεση watermark. Το Electron προσθέτει μόνο τις λειτουργίες desktop· ο editor και το template παραμένουν στο `src/` για μελλοντική ενσωμάτωση στο CRM. Το preload εκθέτει μόνο τρεις συγκεκριμένες ενέργειες, όχι γενική πρόσβαση σε αρχεία ή Node.js.
