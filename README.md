# LEAF Presentation Builder 1.1

Αυτόνομη εφαρμογή React για παρουσιάσεις ακινήτων. Περιλαμβάνει το εγκεκριμένο πράσινο–χρυσό πρότυπο, τα 7 ακίνητα του Πειραιά και 21 επιλεγμένες εικόνες.

## Εφαρμογή Windows (.exe)

Για να φτιάξεις installer, τρέξε `BUILD-WINDOWS.cmd`. Οι συνεργάτες λαμβάνουν μόνο το `LEAF-Presentations-Setup.exe`. Δες το **[docs/WINDOWS.md](docs/WINDOWS.md)** για build, GitHub Actions, χρήση και τους ελέγχους που απομένουν στα Windows. Το ZIP περιέχει κώδικα και ρύθμιση build, όχι έτοιμο εκτελέσιμο.

## Εκκίνηση της web έκδοσης στα Windows

Απαιτείται Node.js 22.12+ (ή 24 LTS) και npm.

1. Κάντε εξαγωγή ολόκληρου του ZIP σε έναν φάκελο.
2. Ανοίξτε terminal στον φάκελο `leaf-presentation-builder`.
3. Τρέξτε:

```bash
npm ci
npm run dev
```

Ανοίξτε τη διεύθυνση **Local** που εμφανίζει το terminal. Κρατήστε το terminal ανοιχτό όσο χρησιμοποιείτε την εφαρμογή. Εναλλακτικά, μετά την εγκατάσταση Node.js, τρέξτε το `START-WINDOWS.cmd`.

Η πρώτη εγκατάσταση χρειάζεται internet για τις εξαρτήσεις. Μετά την εγκατάσταση, η εφαρμογή λειτουργεί τοπικά χωρίς υπηρεσία, API key ή συνδρομή. Μην ανοίγετε το `index.html` με διπλό κλικ: απαιτείται ο τοπικός server.

## Χρήση

- **Στοιχεία παρουσίασης:** τίτλος, περιοχές, ημερομηνία, λογότυπο, επικοινωνία, εμφάνιση/απόκρυψη επισκόπησης, πίνακα και τελικής σελίδας.
- **Ακίνητα:** προσθήκη, αντιγραφή, διαγραφή, μετακίνηση με ↑/↓ και προσωρινή απόκρυψη μέσω «Εμφάνιση στην παρουσίαση».
- **Κείμενα:** έως 650 χαρακτήρες περιγραφής, 8 δυνατά σημεία των 90 χαρακτήρων, υποσημείωση έως 180 χαρακτήρες. Στην εξαγωγή γίνεται έλεγχος μήκους/επικάλυψης· αν ζητηθεί, συντομεύστε το κείμενο.
- **Εικόνες:** έως 3 ανά ακίνητο, JPG/PNG/WebP, έως 15 MB η καθεμία. Αντικατάσταση, αφαίρεση, σειρά, λεζάντες. Οι νέες εικόνες αποθηκεύονται ως JPEG έως 1600 px για λογικό μέγεθος έργου. Δεν υπάρχει αυτόματη αφαίρεση υδατογραφήματος.
- **3D:** ενεργοποιήστε την αντίστοιχη επιλογή όταν πρόκειται για απεικονίσεις και όχι φωτογραφίες αποπερατωμένου ακινήτου.
- **Όλες οι σελίδες:** προεπισκόπηση ολόκληρης της παρουσίασης.

## Αποθήκευση έργου και μεταφορά

Η **Αποθήκευση έργου** κατεβάζει ένα `.leaf.json` με όλα τα στοιχεία, λογότυπο και φωτογραφίες ενσωματωμένα. Αυτό είναι το επεξεργάσιμο αρχείο σας. Φυλάξτε το σε φάκελο/backup και στείλτε το σε συνάδελφο για να το ανοίξει στην ίδια εφαρμογή.

Η **Άνοιγμα έργου** επαναφέρει τα περιεχόμενά του. Συμπεριλαμβάνεται το `examples/LEAF_Piraeus.leaf.json` ως έτοιμο παράδειγμα. Ανώτατο μέγεθος εισαγωγής/εξαγωγής: 60 MB, έως 40 ακίνητα. Οι συνοπτικές σελίδες χωρίζονται αυτόματα ανά 8 ακίνητα.

Υπάρχει αυτόματη αποθήκευση **ενός τοπικού πρόχειρου** μέσω IndexedDB. Δεν είναι κοινόχρηστη βάση ή υποκατάστατο του αρχείου έργου: καθαρισμός browser, αλλαγή διεύθυνσης/θύρας ή υπολογιστή μπορεί να κάνει το πρόχειρο μη διαθέσιμο. Το νέο έργο και η φόρτωση παραδείγματος αντικαθιστούν αυτό το πρόχειρο. Κατεβάζετε αρχείο έργου πριν αλλάξετε εργασία.

## PDF για τον πελάτη

1. Πατήστε **Εξαγωγή PDF**. Η εφαρμογή περιμένει να φορτωθούν οι εικόνες και ελέγχει πιθανή επικάλυψη κειμένων.
2. Πατήστε **Εκτύπωση / Αποθήκευση ως PDF**.
3. Στο Chrome/Edge επιλέξτε προορισμό **Αποθήκευση ως PDF**, όλες τις σελίδες, χωρίς περιθώρια, κλίμακα 100%, χωρίς κεφαλίδες/υποσέλιδα και ενεργά **Γραφικά φόντου**.
4. Το CSS ζητά μέγεθος 16:9 (254 × 142,875 mm). Αν ο browser επιβάλλει A4, επιλέξτε οριζόντιο προσανατολισμό και προσαρμογή στη σελίδα. Θα υπάρχει λευκό περιθώριο λόγω διαφορετικής αναλογίας.
5. Ελέγξτε την προεπισκόπηση εκτύπωσης πριν αποθηκεύσετε.

Η εξαγωγή χρησιμοποιεί τον browser, όχι υπηρεσία παραγωγής PDF. Οι ρυθμίσεις και η σελιδοποίηση μπορεί να διαφέρουν μεταξύ browsers· για σταθερή διαδικασία χρησιμοποιήστε το ίδιο Chrome/Edge και ίδιες ρυθμίσεις στην ομάδα.

## Ανάπτυξη

```bash
npm test
npm run build
npm run preview
```

- `src/App.jsx`: editor και διαχείριση έργου.
- `src/components/Slides.jsx`: πρότυπο παρουσίασης και εκτυπώσιμη έκδοση.
- `src/lib/project.js`: μορφή δεδομένων, validation, σειρά/σελιδοποίηση.
- `src/lib/files.js`: εισαγωγή/εξαγωγή, εικόνες, IndexedDB.
- `src/data/example.json`: αρχικό παράδειγμα με τοπικές αναφορές assets.
- `public/assets`: λογότυπο και επιλεγμένες εικόνες.
- `docs/CRM-INTEGRATION.md`: οδηγός ενσωμάτωσης στο CRM.

Δεν υπάρχουν αναλυτικά χρήσης, αποστολή email, login, κλήσεις AI ή μεταφόρτωση στοιχείων σε server. Ο Vite είναι server ανάπτυξης, όχι παραγωγικό hosting. Τα δεδομένα πελατών δεν πρέπει να γίνονται commit μαζί με τον κώδικα. Το `.gitignore` αποκλείει αρχεία `.leaf.json` εξ ορισμού.

Οι εικόνες του ενσωματωμένου παραδείγματος προέρχονται από το υλικό που παραδόθηκε για τη LEAF· σε 18 έγινε αφαίρεση υδατογραφήματος με AI κατά την προετοιμασία της παρουσίασης. Δεν παρουσιάζονται ως πρωτότυπα αρχεία κάμερας. Τα δύο υπό κατασκευή ακίνητα επισημαίνονται ως 3D.

## Έλεγχοι παράδοσης

Πέρασαν οι έλεγχοι δεδομένων/σελιδοποίησης και το production build. Έγινε δοκιμή σε browser για επεξεργασία τιμής, αναδιάταξη εικόνων, εξαγωγή με ενσωματωμένες φωτογραφίες και επανεισαγωγή του αρχείου. Η τελική αποθήκευση μέσω του διαλόγου εκτύπωσης πρέπει να ελεγχθεί και στον δικό σας Chrome/Edge.
